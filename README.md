## ⚙️ Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. (Optional) Create virtual environment

```
python -m venv venv
```

### 3. Activate it

Windows:

```
venv\Scripts\activate
```

Mac/Linux:

```
source venv/bin/activate
```
